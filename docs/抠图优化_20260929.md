# 抠图与透明边缘优化（2026-09-29）

重点是发丝保留、减少旧背景色残留，以及预览和导出的一致性。

## 变化

- AI 输入使用无损 PNG，避免再次 JPEG 压缩细发丝、纹理和颜色。
- 清理蒙版时保留模型确认的背景小孔、高置信小主体，以及和主体相连的半透明细发丝；远离主体的低置信杂点仍清理。
- 平滑背景下利用可靠的前景/背景颜色估计半透明边缘，复杂背景时保守处理。
- 识别透明图片的所有像素，包括很淡的透明度和单像素细线。
- 蒙版缩小按像素覆盖面积采样，避免非整数缩放时发丝错位或忽然消失。
- 主体颜色缩小时按透明度加权，避免已去掉的背景颜色重新混进边缘；保留笔和边缘扩展仍可恢复原图颜色。
- 收缩/扩展支持 0.25 px 步进，减少一次整像素收缩造成的发丝丢失。
- 增加黑底、白底、绿底和灰度蒙版检查；检查视图不改变图片背景，也不进入导出。
- AI 结果过期时不会覆盖等待期间的新编辑；模型缺失回退时会显示实际模式。
- 补齐软件专用 `.venv` 运行组件，桌面原快捷方式保持可用。依赖版本记录在 `requirements-lock.txt`。

## 使用

关闭之前的工具窗口，再双击桌面「AI抠图P图」。人物照片选择「人像发丝」，点击「一键抠图」。
抠好后先检查黑底和白底，再决定是否少量收缩；细发丝一般不要大幅羽化。
透明底保存为 PNG。接近背景颜色的头发、运动模糊、玻璃等仍可能需要手动修补。
