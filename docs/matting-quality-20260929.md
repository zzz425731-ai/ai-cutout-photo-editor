# 2026-09-29 抠图边缘质量改进与验证

本次保留 BiRefNet_lite / MODNet 模型及原有 API，调整模型输出后的清理、半透明前景去色。旧代码保存在 `_backup_20260929/engine/matting.py`。

## 改动

1. 删除“面积很小就直接填满”的规则。即使是很小的洞，只要模型给出了确定背景，也予以保留，避免填平指缝、耳环和卷发之间的真实空隙。
2. 清理碎块时同时检查置信度、低透明度连接和与主体的距离。保留高置信小前景、与主体有半透明连接的断续发丝、主体附近的细长发丝；仍清除远处低置信噪点。仅凭狭长形状保留会留下背景亮斑，已在灯泡样图验证并加上距离约束。
3. 去色仍以原有 Blur-Fusion 为基础。在邻域存在确定前景和确定背景、背景方差较小时，用正则化的颜色解混合减少边缘旧背景色。低透明度依赖附近前景色以抑制噪声；复杂纹理、缺少可信锚点、解混色明显超出色域时退回原算法。背景二阶矩在缩小之前计算，防止细纹理被缩小抹平而误判成纯色。

## 可重复验证

运行：

```powershell
.\.venv\Scripts\python.exe tests/test_matting_quality.py
.\.venv\Scripts\python.exe tests/test_engine.py matting_samples portrait_mode group_photo matting_edge matting_huge
.\.venv\Scripts\python.exe tests/evaluate_matting_quality.py --infer
```

质量测试 11 项通过。原引擎相关测试 5 项通过，覆盖 8 张样图的通用/人像两种模式、人物去车、合影不丢人、16×16 / 1 像素宽 / 纯色图、6000×4000 大图。此次 24MP 人像用时约 5.16 秒，包含模型与后处理；机器、缓存状态不同，用时会变化。

### 已知真值的合成数据

前景和背景颜色、alpha 均由测试生成。下表的数值是半透明像素去色后合成误差：`mean(abs(F_est - F_true) * alpha) * 255`，越低越好。

| 场景 | 原算法误差 | 新算法误差 |
| --- | ---: | ---: |
| 深色前景 / 浅色背景 | 12.20 | 0.68 |
| 棕色前景 / 粉色背景 | 7.42 | 0.36 |
| 深色前景 / 绿色背景 | 4.37 | 0.26 |
| 浅色前景 / 深色背景 | 8.71 | 0.40 |
| 高频棋盘背景 | 5.79 | 5.79 |
| 随机纹理背景 | 8.81 | 8.81 |

前四个平滑背景用例的误差降低 94%–95%，**仅表示这些已知精确 alpha 的合成测试结果，不能等同于真实照片整体准确率提升**。纹理背景保持原算法，避免不可靠的激进去色。

同时包含真孔洞、半透明发丝连接、小高置信前景及低置信噪点的 alpha 合成用例，在受影响的 71 个像素上，平均绝对误差由 0.534 降至 0。

### 真实照片对照

结果位于 `tests/out/quality_20260929/`，含 8 张同一 raw alpha 下的前后深/浅背景对照、最终 alpha，以及 `metrics.json`。首次运行实际模型得到的 raw alpha 保存为 `.npy`；重复评估复用这些缓存，消除模型波动。照片没有人工 alpha 真值，差异统计仅用于定位检查区域，不是准确率分数。

- `portrait-of-woman_portrait_comparison.jpg`：原算法将两侧细长发丝删除成不连续片段；新算法保留连接，共有 20,243 个原模型支持的边缘像素不再被清理误删。黑底、白底放大对照可见发丝连续性改善。
- `woman-with-afro_medium_portrait_comparison.jpg`：保留原先被清理删除的卷发小片段，避免边缘局部被挖空。
- 灯泡、面包、蝴蝶、柯基、足球、靠车人物也做了对照及模型回归。

## 限制

本次不能找回模型完全未检测到的头发，也不能保证背景与发色非常相近、严重运动模糊、透明玻璃等场景自动准确。高置信模型误判仍可能保留，需要手工蒙版修正。真实背景孔洞是否保留仍依赖模型给出的透明度；新增规则保证不会仅因孔洞面积小就将确定背景填满。
